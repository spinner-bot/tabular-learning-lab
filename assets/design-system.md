# 课程设计系统 v0.1

## 视觉语义

- 背景：暖白 `#f7f8f5`；正文：深墨 `#17212b`。
- 主强调色：靛蓝 `#3155d4`，用于链接、导航和可操作控件。
- 辅助色：青绿 `#168f83` 表示过程/正确；琥珀 `#c77700` 表示提醒/边界；红色只用于错误状态。
- 颜色不单独承担信息，图示同时使用文字、线型或形状。

## 页面结构

1. 顶部课程栏：课程名、编号、阶段状态。
2. 侧栏目录：当前小节高亮，窄屏变为折叠菜单。
3. 主内容：目标、动机、直觉、正式机制、案例、交互、误区、自测、来源。
4. 底部导航：上一节、课程地图、下一节。

## 交互约定

- 所有按钮使用原生 `button` 并有可见焦点。
- 交互图默认状态可读，参数改变后同步更新文字说明。
- 代码复制成功或失败都给出反馈。
- `prefers-reduced-motion: reduce` 时关闭非必要动画。
- 外部依赖不是阅读课件的必要条件；样板课使用原生 HTML/CSS/JS。

## 内容约定

- 首次术语按“中文名（English）—直觉—正式定义—例子”出现。
- 公式必须解释符号，结论必须说明适用边界。
- 模拟数据显式标注；真实实验必须留运行记录。
