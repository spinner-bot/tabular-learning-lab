# TabPFN 版本事实复核记录

核验日期：2026-10-10

本次复核直接打开 Prior Labs 官方仓库和 Models 页面，结果只用于更新版本敏感事实，不替代本机运行验证。

## 已确认的官方信息

- 官方仓库当前 quick start 以 TabPFN-3.5 为默认模型，提供 `TabPFNClassifier`、`TabPFNRegressor` 和版本选择器示例。
- 官方页面要求 Python 3.10+，说明首次使用会下载 checkpoint，并给出 GPU 推荐、CPU 可行性提示和批量预测建议。
- Models 页面按版本分别列出可用性、行/列/类别边界和许可；例如 TabPFN-3.5/3.5-Fast、TabPFN-3、2.6、2.5 与 v2 的限制并不相同。
- 官方仓库明确区分 Apache 2.0 代码许可与模型权重许可；模型权重可能是非商业许可，不能把代码许可当作权重许可。
- 本次页面快照给出的代表性边界为：TabPFN-3.5 与 3.5-Fast 最大训练行数 1,000,000、最大列数 20,000；TabPFN-3 最大训练行数 1,000,000、最大列数 2,000；TabPFN-2.6/2.5 为 100,000 行、2,000 列；TabPFNv2 为 10,000 行、500 列。页面同时提示行列上限存在联动，不能把各自最大值无条件相乘。
- TabPFN-3/3.5 原生支持最多 160 类分类；超过该范围应单独考察 many-class 扩展。以上是官方 checkpoint 页面边界，不是本机性能保证。
- 官方 README 当前说明 CPU 下 TabPFN-3/3.5/3.5-Fast 的中等规模限制为最多 5,000 个样本，并建议使用 GPU；这与模型的理论/页面上限是不同维度，课程中分开记录。

## 尚未确认的内容

- 当前 Windows 工作站仍无法导入 PyTorch `c10.dll`，没有完成 checkpoint 下载、认证、预测或资源实测。
- 官方上限不等于当前硬件上的可行性；CPU 时间、显存/内存和批量大小仍需在可运行环境中测量。
- 当前页面的模型家族、许可和资源表可能继续变化；后续更新必须新增日期化快照，不覆盖本记录。
