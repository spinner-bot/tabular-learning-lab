# 第 14 节计划：FT-Transformer

- 学习目标：说明数值/类别特征 token 化及 Transformer 层在表格中的作用。
- 核心问题：为什么对每个特征建立 token，能表达跨特征关系？
- 知识点：feature token、数值编码、类别 embedding、注意力堆叠。
- 案例：小型表格的 token 流程。
- 图示/交互：token 到注意力输出流程。
- 代码：以维护良好的实现为准，锁定版本并记录。
- 自测：输入编码、与 MLP 区别、计算成本、论文结论边界、实现差异。
- 来源：R03及作者实现。
- 难点：原论文 benchmark 不能推广成所有深度模型排名。
