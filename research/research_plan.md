# 阶段 A 研究计划

## 研究日期

首次核验日期：2026-10-09。后续涉及“当前”“最新”或 API 的内容必须重新记录核验日期。

## 目标

为 30 节表格学习课程建立可追溯的事实基础，重点确认：

1. 表格学习、树模型、集成学习和深度表格模型的基本机制。
2. XGBoost、CatBoost、FT-Transformer 的原始论文结论及适用范围。
3. TabPFN/PFN 的原始方法、预训练任务、上下文推断、版本演进和当前官方使用方式。
4. 评估指标、数据划分、数据泄漏、公平基准和可复现实验要求。

## 来源策略

- 第一优先级：原始论文、会议论文、作者技术报告。
- 第二优先级：官方代码仓库、官方文档、模型卡和 API 文档。
- 第三优先级：严谨的基准研究和综述。
- 博客、论坛和搜索摘要只作为线索，不单独支撑关键结论。

## 执行顺序

1. 建立核心来源清单和版本时间线。
2. 将关键主张拆成可核验条目，填入事实核验矩阵。
3. 对有争议或版本依赖的内容记录交叉来源和开放问题。
4. 将核验结论映射到课程章节和逐节计划。
5. 阶段 A 结束时检查每个核心主张是否有直接来源，未确认内容是否明确标注。

## 研究边界

本阶段不制作正式 HTML，不把搜索结果摘要当作已验证事实，不把论文中的特定 benchmark 结果泛化为所有任务上的模型排名。
