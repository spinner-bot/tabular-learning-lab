# 阶段 A 与最终项目验收标准

## 阶段 A 门禁

- [ ] 研究计划明确来源优先级、核验日期和执行顺序。
- [ ] 核心事实已进入矩阵，且每条有直接来源或明确标记未核验。
- [ ] 版本差异和开放问题有单独记录。
- [ ] 课程地图覆盖 30 节、先修关系和阶段安排。
- [ ] 30 份逐节计划已建立，包含目标、机制、案例、图示、代码、自测和来源。
- [ ] 术语、符号、版本基准和评估协议已记录在决策文件。
- [ ] 阶段报告列出已完成、未完成和阻塞项。

## 每节课门禁

- [ ] 目标可验证，先修关系清楚。
- [ ] 首次术语有中文、英文、直觉、正式定义和例子。
- [ ] 机制、公式、案例、图示/交互和边界完整。
- [ ] 代码已执行验证，或明确写明未验证。
- [ ] 至少 3 个误区和至少 5 道带解析的自测题。
- [ ] 引用真实、可访问且支持具体主张。
- [ ] 交互、导航、键盘焦点、窄屏和减少动效设置已测试。

## 阶段推进规则

当前阶段未通过，不进入下一阶段。阶段报告和验证证据不得删除或覆盖。
