TabPFN 结果解释、校准与不确定性

先修：03、20–21 · 后续：23 数据处理

一个预测概率不仅要看“猜对没有”，还要看它是否与长期频率相符。准确率、置信度、校准和不确定性是不同概念。

学习目标

  • 区分准确率、置信度和校准。
  • 解释 Reliability Diagram、Brier Score 和 ECE。
  • 说明分布偏移下概率输出的风险。
  • 核对 TabPFN 具体版本是否支持某种解释/不确定性功能。

1. 什么是校准

若一组预测概率约为 0.8 的样本，长期实际正例比例也约为 0.8，可称这组预测在该范围内较好校准。校准不等于准确率：一个模型可以预测得准但概率过度自信。

置信度单个输出对自身预测的概率/分数。
校准概率与长期频率之间的对应关系。
Brier概率预测与二元标签平方误差的平均。
ECE按置信度分箱比较平均置信度和准确率的汇总。

3. 解释边界

输出概率不是现实世界中的真实概率保证。分布偏移、类别比例变化和样本选择会破坏校准。TabPFN 具体版本的解释扩展、embedding 或不确定性功能必须查官方 API/扩展说明，不可从概率输出自动推断。

from sklearn.calibration import calibration_curve; fraction,mean=calibration_curve(y_test,probabilities,n_bins=10)

该代码行未单独执行；同一 calibration API 已由 校准 smoke test 覆盖。

4. 易错点

误区：准确率 90% 就表示概率校准。正确理解：准确率和概率可靠性不同。

误区：最高概率就是确定性。正确理解：它仍可能受分布偏移和模型失配影响。

误区：ECE 一个数字就完整描述校准。正确理解：分箱方式、样本量和图形也需报告。

5. 自测

0.8 概率组的实际正例率约 0.8 说明什么？

该概率区间具有较好的校准表现。

校准和准确率是否相同？

不同；前者关注概率与频率，后者关注分类是否正确。

分布偏移为何影响校准？

训练/校准时的概率与部署环境的频率关系可能变化。

ECE 是否完全客观？

它依赖分箱和估计方式，不能脱离定义解释。

如何确认某版本有解释功能？

查对应官方文档、扩展仓库和实际 API，不凭模型名称推断。
