XGBoost：目标函数与工程设计

先修：06、08 · 后续：10 CatBoost

XGBoost 是一个可扩展的树提升系统。本节把它拆成统计目标和处理稀疏数据、近似分裂与系统资源的工程设计两层。

学习目标

  • 解释损失加正则化的目标。
  • 说明一阶/二阶 Taylor 近似的作用。
  • 理解叶节点权重、分裂收益和关键参数。
  • 区分 XGBoost 论文系统贡献与当前库 API。

1. 目标函数

第 t 轮可概念化为 Obj=Σᵢ l(yᵢ,ŷᵢ⁽ᵗ⁻¹⁾+fₜ(xᵢ))+Ω(fₜ)。第一项衡量新增树后的损失，Ω 约束树叶数和叶权重。二阶近似用一阶梯度 gᵢ 和二阶项 hᵢ 汇总每个叶的收益。

正则化惩罚复杂树或过大的叶权重。
gamma要求分裂带来足够收益。
lambda/alpha控制 L2/L1 约束。
缺失值方向实现默认路径，行为以版本文档为准。

采样参数（如行/列子采样）可改变每轮看到的信息和树之间的相关性；量化/近似分裂把连续特征映射到候选桶，以换取速度或内存效率。它们影响的是具体训练协议，不是无条件的效果保证。

2. 工程设计

原始论文还讨论稀疏感知算法、加权分位数 sketch、缓存友好的块结构、并行与 out-of-core 处理。这些是系统设计贡献，不应被压缩成“只是更快的 GBDT”。

4. 易错点

误区：所有参数都直接来自原始论文。正确理解：论文机制、库实现和版本 API 要分开核对。

误区：二阶信息保证模型一定更好。正确理解：它改变优化近似，效果仍依赖数据和协议。

误区：缺失值处理不需要实验检查。正确理解：默认方向和预处理必须按版本验证。

5. 自测

目标函数为什么包含正则化？

约束树复杂度和叶权重，降低过拟合风险。

g 和 h 分别表示什么？

常见记号中 g 是一阶梯度，h 是二阶导数或 Hessian 对角项。

gamma 控制什么？

分裂需要带来足够收益，否则不增加树结构。

论文的系统贡献有哪些？

稀疏感知、加权分位数 sketch、缓存友好结构和并行等。

为什么不能只报告最佳一次分数？

需要记录拆分、预算、种子和波动，避免选择性报告。
