数据处理：缺失值、类别特征与特征工程

先修：01–04、10、22 · 后续：24 可信基准

预处理不是清理阶段的装饰，而是实验协议的一部分。它必须在正确的数据划分和预测时间点内执行。

学习目标

  • 区分缺失机制和常见插补策略。
  • 选择类别编码、缩放和异常值处理方案。
  • 识别特征选择与目标泄漏。
  • 把预处理放入可复现 pipeline。

1. 缺失不是一种情况

MCAR缺失与观测值和未观测值都无关的理想情况。
MAR缺失可由已观测变量解释。
MNAR缺失与未观测值本身有关，需要更强假设。
缺失指示器缺失本身有语义时可作为特征，但要防止泄漏。

2. 正确的数据流

先切分训练/验证/测试，再只用训练部分拟合插补器、编码器和缩放器。测试集只能通过已经固定的变换进入模型。特征工程还需问：预测时点能否获得这列？

3. 代码示例（未执行）

from sklearn.compose import ColumnTransformer; from sklearn.pipeline import Pipeline; from sklearn.impute import SimpleImputer; numeric=Pipeline([("impute",SimpleImputer())]); preprocess=ColumnTransformer([("num",numeric,numeric_columns)])

应在交叉验证管道内拟合预处理。

4. 易错点

误区：先全数据插补不会泄漏。正确理解：全数据统计量包含测试信息。

误区：类别编号可以直接当连续数值。正确理解：编码要匹配模型和语义。

误区：删除缺失行总是最干净。正确理解：可能引入选择偏差或损失重要样本。

5. 自测

插补器应在哪些数据上拟合？

训练折或训练集。

缺失指示器何时有价值？

缺失过程有预测语义且在部署时同样可观测时。

MNAR 的难点是什么？

缺失与未观测值相关，单靠已观测数据难以识别。

特征工程要检查什么时间条件？

预测时点是否已经能获得该特征。

为什么使用 pipeline？

把变换和模型绑定到正确的训练流程，减少泄漏和不可复现。
