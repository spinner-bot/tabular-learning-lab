Bagging、随机森林与模型集成

先修：05–06 · 后续：08 Boosting

一棵树容易受训练样本扰动影响。Bagging 通过重采样训练多棵树，再聚合预测，目标是让整体更稳定。

学习目标

  • 解释 bootstrap 重采样。
  • 区分 Bagging 与随机森林的样本/特征随机性。
  • 说明集成降低方差的条件。
  • 解释 OOB 评估的基本思路。

1. 从一棵树到很多棵树

Bootstrap 是从训练集有放回抽取同样大小的样本。每棵树看到的数据略有不同，因而犯错方式也可能不同。分类可以投票，回归可以平均。

Bagging重采样训练和聚合多个模型。
随机森林通常还在每个分裂处随机抽取候选特征。
相关性基学习器越相似，平均收益越有限。
OOB某棵树未抽到的样本，可用于近似评估。

2. 方差为什么可能下降

若每棵树的误差不是完全相同，平均会抵消一部分随机波动。随机特征子集让树之间更不相似，但也可能增加单树偏差。

3. 代码示例（未执行）

from sklearn.ensemble import RandomForestClassifier; forest=RandomForestClassifier(n_estimators=200,oob_score=True,random_state=42,n_jobs=-1); forest.fit(X_train,y_train); print(forest.oob_score_)

OOB 估计不等同于独立测试集。

4. 易错点

误区：树越多一定降低所有误差。正确理解：通常主要改善方差，计算和内存会增加。

误区：随机森林就是复制同一棵树。正确理解：样本和候选特征随机性使树结构不同。

误区：OOB 分数替代所有测试设计。正确理解：它是方便的内部估计。

5. 自测

Bootstrap 是否有放回？

是，同一样本可能被抽中多次，也可能未被抽中。

为什么随机选特征？

减少树之间的相关性，可能提升聚合收益。

分类森林如何聚合？

常见方式是多数投票或聚合类别概率。

Bagging 和 Boosting 的主要差别？

Bagging 通常并行训练相对独立模型；Boosting 逐轮关注当前误差。

方差下降是否保证验证分数上升？

不保证，偏差、数据和超参数也会影响结果。
